# ميدان فِت — هيكلة الملفات

```
maydan-fit/
├── login.html              ← تسجيل الدخول + الترحيب + الإعداد الأولي
├── index.html              ← التطبيق الرئيسي (الرئيسية/الخطة/تمرين/تقدمي/الاستشفاء)
└── assets/
    ├── css/style.css       ← كل التنسيقات
    ├── js/
    │   ├── data-loader.js  ← يجلب ملفات JSON ثم يشغّل core.js والصفحة
    │   ├── core.js         ← مشترك بين الصفحتين (الحالة، المحرك، أدوات العرض)
    │   ├── login.js        ← منطق صفحة تسجيل الدخول فقط
    │   └── main.js         ← منطق التطبيق الرئيسي فقط
    ├── data/               ← قاعدة البيانات (JSON) — عدّل هون أرقام/نصوص البرامج
    │   ├── goals.json        (أهداف التدريب: تضخيم، قوة قصوى...)
    │   ├── sports.json       (الرياضات والمستويات والفئات العمرية)
    │   ├── templates.json    (تمارين كل يوم تدريب)
    │   ├── programs.json     (التقسيمات والبرامج الجاهزة)
    │   └── strings.json      (الترجمة للإنجليزي + القصص/الاقتباسات)
    └── img/
        ├── logo.jpg        ← شعار شاشة البداية
        └── hero.jpg        ← صورة شاشة الترحيب
```

## مهم: افتحه عبر خادم محلي، مو بفتح الملف مباشرة

المتصفحات تمنع قراءة ملفات JSON بـ`fetch` عند فتح `login.html` مباشرة (نقر مزدوج / `file://`).
لازم خادم محلي بسيط. من داخل مجلد `maydan-fit`:

```bash
python3 -m http.server 8000
```

وبعدين افتح بالمتصفح: `http://localhost:8000/login.html`

(أو أي خادم آخر تفضّله: `npx serve`, إضافة Live Server بـ VS Code، إلخ.)

## كيف تعدّل

- **نص أو ترجمة** → `assets/data/strings.json`
- **برنامج تمرين جديد أو تعديل تمارين يوم** → `assets/data/templates.json` و`programs.json`
- **شكل/ألوان** → `assets/css/style.css`
- **سلوك/شاشات** → `assets/js/login.js` (قبل تسجيل الدخول) أو `assets/js/main.js` (بعد الدخول)

بيانات المستخدم (الاسم، السجلات، الجلسات) تُحفظ بـ`localStorage` بالمتصفح نفسه — نفس المفتاح `maydanfit.v2` تستخدمه الصفحتان.
