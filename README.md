# ميدان فِت — هيكلة الملفات

```
maydan-fit/
├── login.html              ← تسجيل الدخول + الترحيب + الإعداد الأولي
├── index.html              ← التطبيق الرئيسي (الرئيسية/الخطة/تمرين/تقدمي/الاستشفاء)
└── assets/
    ├── css/style.css       ← كل التنسيقات
    ├── js/
    │   ├── data-loader.js  ← يجلب ملفات JSON ثم يشغّل core.js والصفحة
    │   ├── core.js         ← مشترك بين الصفحتين (الحالة، المحرك، أدوات العرض)
    │   ├── login.js        ← منطق صفحة تسجيل الدخول فقط
    │   └── main.js         ← منطق التطبيق الرئيسي فقط
    ├── data/               ← قاعدة البيانات (JSON) — عدّل هون أرقام/نصوص البرامج
    │   ├── goals.json        (أهداف التدريب: تضخيم، قوة قصوى...)
    │   ├── sports.json       (الرياضات والمستويات والفئات العمرية)
    │   ├── templates.json    (تمارين كل يوم تدريب)
    │   ├── programs.json     (التقسيمات والبرامج الجاهزة)
    │   └── strings.json      (الترجمة للإنجليزي + القصص/الاقتباسات)
    └── img/
        ├── logo.jpg        ← شعار شاشة البداية
        └── hero.jpg        ← صورة شاشة الترحيب
```

## مهم: افتحه عبر خادم محلي، مو بفتح الملف مباشرة

المتصفحات تمنع قراءة ملفات JSON بـ`fetch` عند فتح `login.html` مباشرة (نقر مزدوج / `file://`).
لازم خادم محلي بسيط. من داخل مجلد `maydan-fit`:

```bash
python3 -m http.server 8000
```

وبعدين افتح بالمتصفح: `http://localhost:8000/login.html`

(أو أي خادم آخر تفضّله: `npx serve`, إضافة Live Server بـ VS Code، إلخ.)

## كيف تعدّل

- **نص أو ترجمة** → `assets/data/strings.json`
- **برنامج تمرين جديد أو تعديل تمارين يوم** → `assets/data/templates.json` و`programs.json`
- **شكل/ألوان** → `assets/css/style.css`
- **سلوك/شاشات** → `assets/js/login.js` (قبل تسجيل الدخول) أو `assets/js/main.js` (بعد الدخول)

بيانات المستخدم (الاسم، السجلات، الجلسات) تُحفظ بـ`localStorage` بالمتصفح نفسه — نفس المفتاح `maydanfit.v2` تستخدمه الصفحتان.

## تسجيل الدخول + Google Sheets

شاشة الدخول صارت فعلية بالكامل: إنشاء حساب / تسجيل دخول ببريد وكلمة مرور، وترسل البيانات لـ Google Apps Script اللي بتكتبها بورقة Google Sheet. **لازم تحدّث كود الـ Apps Script على حسابك** عشان يشتغل:

1. افتح مشروع Apps Script المربوط بالـ Google Sheet متاعك (نفس الرابط `/exec` يلي أعطيتني ياه).
2. امسح الكود القديم بالكامل واستبدله بمحتوى ملف **`google-apps-script.gs`** الموجود بهاد المجلد.
3. تأكد إن الورقة اسمها بالضبط **Users**، وصف الهيدر (الصف الأول) فيها 21 عمود بنفس الترتيب يلي حطيته (موجود بأول الملف كتعليق).
4. من Deploy → Manage deployments → عدّل الـ deployment الموجود واختر **New version** ثم Deploy (مهم: لازم نسخة جديدة، مو بس حفظ الملف).
5. رابط الـ `/exec` بيضل نفسه، فما في داعي تغيّر أي شي بالتطبيق.

**شو تغيّر بالضبط عن الكود القديم:**
- بدل `doPost` يدعم إجراءين فقط (signup/login بـ4 أعمدة)، صار يدعم 3 إجراءات: `signup` (ينشئ الحساب فاضي ما عدا البريد/كلمة المرور)، `login` (يتحقق ويرجّع الملف الشخصي الكامل لو موجود، عشان لو المستخدم سجّل دخول من جهاز جديد يرجع ياخد بياناته)، و`saveProfile` (يحفظ/يحدّث الـ21 عمود بعد ما يخلّص المستخدم شاشات الإعداد، وكمان كل مرة يعدّل إعداداته).
- كلمة المرور لسا بتنحفظ نص صريح بدون تشفير، متل ما كانت بالكود الأصلي — هاد قرار مقصود مني بناءً على طلبك.

**تدفّق الاستخدام:** أول مرة → إنشاء حساب (بريد + كلمة مرور) → شاشات الإعداد (الاسم، الجنس، تاريخ الميلاد، الطول/الوزن بالوحدة يلي يحبها، نمط الحياة، أيام التدريب...، الكارديو، مدة الجلسة، مكان التمرين) → يُحفظ كل شي بالـ Sheet. المرات الجاية → تسجيل دخول بنفس البريد وكلمة المرور، ولو كان على جهاز/متصفح جديد بيرجع يجيب بياناته تلقائياً من الـ Sheet.

## الكارديو / مدة الجلسة / مكان التمرين — بتأثر فعلياً على الخطة (قسم الجيم فقط)

- **مكان التمرين** (جيم / منزل / خارجي): لما تختار منزل أو خارجي، أسماء تمارين الجيم (بنش بريس، سكوات بار، سحب علوي...) بتنستبدل تلقائياً بتمارين مكافئة تناسب المكان (دمبل بالمنزل، وزن الجسم بالخارج). شوف `HOME_SUB`/`OUT_SUB` بـ`assets/js/core.js` إذا حبيت تضيف/تعدّل تمارين بديلة.
- **مدة الجلسة** (30/45/60/90 دقيقة): 30 دقيقة = أول 3 تمارين بس (الأساسية)، 45 = أول 5، 60 = الخطة الكاملة متل ما هي (الافتراضي، ما بيتغيّر شي)، 90 = الخطة الكاملة + مجموعة إضافية لكل تمرين.
- **إضافة الكارديو**: لو "نعم"، بتنضاف حركة كارديو ختامية (15–20 دقيقة) آخر كل يوم تدريب بالجيم.
- هاد الثلاثة تقدر تعدّلهم بأي وقت من **الإعدادات** بالتطبيق الرئيسي كمان، مو بس وقت الإعداد الأولي.
